### 2. 어떤 업무 문제를 해결하려 했는가?

- **확인된 사실:** AI가 금융 의사결정과 고객 서비스에 관여할 때 생기는 책임소재, 데이터 통제, 보안과 소비자 보호 문제를 다룹니다.

### 3. AI가 어떤 시스템·데이터와 연결됐는가?

- **확인된 사실:** 고객정보 분석, 리스크·데이터 분석, 상품 추천·가입·결제가 언급됩니다.
- **아직 알 수 없는 내용:** 특정 금융회사의 DB·API·모델 구조는 공개되지 않았습니다.

### 4. 무엇이 자동화됐고 무엇은 사람이 확인하는가?

- **확인된 사실:** AI는 보조수단이며 최종 의사결정과 책임은 임직원이 맡아야 한다고 명시했습니다.

### 5. 실제 성과를 보여주는 근거가 있는가?

- **확인된 사실:** 공식 가이드라인과 위험관리·보안 문서 시행 계획은 확인됩니다.
- **아직 알 수 없는 내용:** 처리 시간이나 오류율 같은 현장 성과는 없습니다.

### 6. AI 솔루션·업무자동화 개발자는 어떤 일을 했는가?

- **자료를 바탕으로 한 해석:** 정책을 사용자 권한, 사람 승인, 감사 로그, 데이터 품질 검사와 이상 알림 기능으로 구현합니다.

### 7. 나의 기존 경험과 연결되는 역량은 무엇인가?

- Java 운영개발에서 경험한 권한 관리, 장애 기록, 변경 이력과 운영자 승인 구조가 직접 연결됩니다.

### 8. 더 공부하거나 직접 만들어볼 것은 무엇인가?

- 고위험 요청은 자동 처리하지 않고 담당자 승인함으로 보내며 처리 이력을 남기는 Java API를 만들어볼 수 있습니다.

### 6. AI 솔루션·업무자동화 개발자는 어떤 일을 했는가?

- **자료를 바탕으로 한 해석:** 승인된 AI 접점, 사내 데이터·업무 API 연결, 민감정보 차단, 사용 기록과 결과 평가를 구현합니다.

### 7. 나의 기존 경험과 연결되는 역량은 무엇인가?

- 시스템 권한, 로그, DB와 API 운영 경험을 안전한 사내 AI 기반 구축에 활용할 수 있습니다.

### 8. 더 공부하거나 직접 만들어볼 것은 무엇인가?

- 승인 문서만 검색하고 민감정보 입력을 차단하며 모든 요청을 기록하는 지식검색 도구를 만들 수 있습니다.
