- AI는 현 단계에서 보조수단이며 최종 의사결정과 책임은 임직원이 수행해야 한다고 명시했다.

- 원문: [국내 기업 GenAI 활용 실태 - 업무 효율 향상 이면의 Shadow AI 리스크](https://www.samsungsds.com/kr/insights/enterprise-genai-usage-survey_part1.html)
- 보조 출처: 없음
- 선정 이유: 개인 활용 증가와 기업 시스템·보안 체계의 간극을 국내 조사 수치로 보여준다.

### 확인된 사실

- 국내 기업·공공기관 임직원 1,750명 조사에서 하루 평균 GenAI 사용 시간은 3.25시간으로 제시됐다.
- 워크플로 자동화 시스템·앱 활용 또는 개발은 13%, 승인 없는 개인 부담 사용은 38%로 제시됐다.
- 응답자 65%가 업무시간 감소를 체감했고 평균 주 1시간 12분을 절약했다고 답했다.

### 해결하려는 업무 문제

- 비공식 AI 사용으로 인한 정보 유출과 품질 편차, 기업 데이터·업무 절차와 연결되지 않은 개인 도구의 한계다.

### 연결된 시스템·데이터

- 기업 데이터 연결, 업무 자동화, 보안·거버넌스를 갖춘 통합 AI 운영 환경을 제안한다.
- 응답 기업의 구체적인 ERP, DB와 API는 공개되지 않았다.

### 자동화 범위와 사람의 확인 지점

- 자동화 개발·활용 비율은 있으나 구체적인 업무 단계와 승인 범위는 없다.

### 성과 수치와 근거 수준

- 근거 수준: 기업 단독 조사·자기보고 결과.
- 표본 수와 지표는 공개됐지만 기업별 생산성 변화와 독립 검증은 없다.

### 개발자 역할에 대한 해석

- 승인된 AI 접점, 사내 데이터·업무 API 연결, 민감정보 차단, 사용 기록과 결과 평가를 구현·운영한다.

### 기존 경험과의 연결

- 시스템 권한·로그·DB·API 관리 경험이 안전한 사내 AI 기반 구축에 이어진다.

### 학습·실습 아이디어

- 승인 문서만 검색하고 민감정보 입력을 차단하며 요청을 감사 로그로 남기는 사내 지식검색 도구.

### 아직 알 수 없는 내용

- 조사 참여 기업별 시스템과 실제 자동화 성공률.

- SAP ERP·S/4HANA 전환과 신규 구축을 위한 `PerfecTwin ERP Edition`을 출시했다.

- ERP 전환 시 방대한 업무 절차를 사람이 설계·반복 검증하면서 생기는 시간과 누락 문제다.

### 연결된 시스템·데이터

- SAP ERP·S/4HANA, 실제 거래 데이터, 업무 프로세스와 운영 데이터를 사용한다.

- 시나리오 생성·실행·분석·조치안·보고서가 자동화된다.
- 오류 수정과 재검증까지 자율 수행하는 기능은 현재 기능이 아니라 향후 계획이다.

### 성과 수치와 근거 수준

- 근거 수준: 기업 단독 주장.
- 회사는 수일 걸리던 시나리오 설계를 수 시간으로 단축할 수 있다고 밝혔다.

### 개발자 역할에 대한 해석

- ERP 업무를 시험 가능한 단계로 나누고 운영 데이터와 실행 도구를 연결하며 결과 품질과 실패 흐름을 관리한다.

### 기존 경험과의 연결

- Java 시스템 변경 영향 분석, 회귀 시험, 장애 원인 조사와 DB 확인 경험이 연결된다.

### 학습·실습 아이디어

- 과거 API 로그로 회귀 시험 시나리오를 생성하고 차이를 분석해 보고서로 남기는 도구.

### 아직 알 수 없는 내용

- 고객 데이터 비식별 처리, 구체적 모델·API와 실제 고객의 전체 기간·오류율 변화.

### 학습·실습 아이디어

- 가상 전표에서 중복·급증·필수값 누락을 찾고 사람이 확정하는 위험 보고 도구.
