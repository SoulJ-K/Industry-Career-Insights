# 최신 PRD 안내

현재 프로젝트의 기준 문서는 아래 **v05** 기획서입니다.

- [기획서-기업용-ai-뉴스수집-2026-09-16-v05.md](../PRD/v05/docs/기획서-기업용-ai-뉴스수집-2026-09-16-v05.md)

현재 구성은 직무 분석 2개 + 재미 읽을거리 2개 + 생각 정리 연습 1개이며, 짧은 본문과 더 읽기 펼치기·접기를 적용합니다. 자료 조사만 요청하면 검증 자료 묶음만 저장하고 뉴스레터 제작은 별도 요청을 기다립니다.

PRD v05는 제작 기준의 갱신입니다. 기존 뉴스레터가 자동으로 수정되거나 새 뉴스레터가 생성된 것은 아닙니다.

새 PRD 버전을 만들 때는 이전 버전을 `PRD/v번호/docs/`에 보존하고, 이 파일의 연결을 새 최신 버전으로 갱신합니다. PRD와 뉴스레터의 버전 번호는 독립적으로 관리합니다.
